# Weather App

Небольшое погодное веб-приложение на HTML, CSS и JavaScript. Позволяет узнать погоду в выбранном городе, посмотреть прогноз на 10 дней и изучить его по часам.

**[Открыть сайт](https://klertgh.github.io/weather-app/)**

## Возможности

- Поиск городов с подсказками: для уточнения местоположения указываются регион и страна.
- Текущая погода: температура, ощущаемая температура, влажность, ветер и осадки.
- Прогноз на 10 дней с максимальной и минимальной температурой.
- Выбор дня в прогнозе: основная карточка показывает показатели этого дня, а почасовой прогноз обновляется.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

## Технологии

- **HTML5, CSS3** — разметка и адаптивная вёрстка с Grid и Flexbox.
- **JavaScript** — работа с DOM, обработка событий, ES-модули и запросы через Fetch API.
- **[Open-Meteo](https://open-meteo.com/)** — данные о погоде и поиск городов через Forecast API и Geocoding API.

## Запуск локально

Склонируйте репозиторий:

```bash
git clone https://github.com/klertgh/weather-app.git
cd weather-app
```

Запустите локальный сервер, например:

```bash
python -m http.server 5500
```

Откройте в браузере [http://localhost:5500](http://localhost:5500). Вместо Python можно использовать расширение **Live Server** в VS Code.

Установка зависимостей и API-ключ не требуются.
